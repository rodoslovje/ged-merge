Changelog

New features and major improvements in GED Merge, newest first.

2026-07-25

  • Slovenian place coordinates in one click. Tools → Geocode places can now fetch all 6035 Slovenian settlements straight from the national land-survey register (GURS), instead of hunting down a gazetteer file. Bilingual Italian and Hungarian names come along, so Isola finds Izola. Stored in your browser, so it keeps working offline.
  • Duplicate finder handles big files. The list now starts at a high match score (≥ 85) so it stays short and actionable, with a score picker to reveal weaker matches on demand. Records that all look like the same person are grouped into clusters — a same-name “parallel branch” folds into one row you can review pair by pair or Reject all at once. Each pair also shows both records' GEDCOM ids, so same-name look-alikes are easy to tell apart.
  • WMS map overlays. The Places map can now draw OGC WMS layers over the base map, not just tile templates — with one-click presets for Slovenia's national GURS maps: historical and current orthophoto, topographic map, cadastral parcels and cadastral municipalities, house numbers, settlements and municipalities. Several layers answer a click on the map: house numbers give the full address (street, number, settlement, post code), a parcel its number, cadastral municipality and area, and the cadastral-municipality layer the katastrska občina with its number.

2026-07-22

  • Saved files now carry the date ({yourfile}.2026-07-22.gedmerge.ged), so successive versions sort by date and never overwrite one another.
  • Same-sex couples are recognised. Parent cards are labelled Parent instead of Father/Mother, and the Health check no longer flags a genuine same-sex marriage.

2026-07-19

  • Geocoding respects the country named in a place, so a place name no longer matches somewhere in the wrong country.
  • The Health check flags places geocoded in some records but not others, and fills the missing coordinates from the file in one click.

2026-07-18

  • Historical map overlays. Add your own historical tile layers in Settings → Map, with a one-click built-in preset covering Slovenia, Croatia & Bosnia in 1877–1918 (Habsburg Spezialkarte 1:75,000).
  • Geocode places can now search online — OpenStreetMap for addresses, and GOV (the Genealogical Gazetteer) for historical, multilingual place names, writing a durable _GOV id back to the file.
  • Life paths on the Places Map. Each person's journey from birth through residences and marriages to death is drawn as a line with direction arrows, with a two-thumb year slider to scrub the period.
  • The Edit view shows a small map of a person's events along their life path.

2026-07-17

  • New chart: Places Map. A person's ancestors' or descendants' events appear as clustered markers, using coordinates the file already carries, with a PNG snapshot export.
  • Geocode places (Tools → Places): match the file's place names against an offline gazetteer and write the accepted coordinates into the GEDCOM.
  • Private data support. Records, notes and media flagged private show a 🔒 toggle and are honoured everywhere — charts, reports, merge and Organize sources.
  • Shared notes keep their identity through edits, so everything referencing a shared note sees the change and the pointer structure round-trips losslessly.

2026-07-16

  • Custom events (EVEN) are now supported on families too, shown under their own title in Edit mode, the merge comparison and the merge.

2026-07-15

  • New Settings → GEDCOM tab. Override any detected file convention — date and place formats, alternate names, source records, citations and page links, and the Matricula/Geneanet languages.
  • Add Source understands archive links: a recognized URL prefills the title, author, place, archive, filing number and page.
  • Many new link types recognized by Organize sources — BillionGraves, dLib.si, Google Books, YouTube, Newspapers.com, Wikipedia, Slovenska biografija and more.
  • Clean up sources is renamed to Organize sources; its sources can now be edited by hand and dead links marked for removal.

2026-07-14

  • New tool: Organize sources (Tools → Sources). Archive links scattered around the file — Matricula, Geneanet, Find a Grave, FamilySearch and more — are grouped by book, grave or record and converted into proper source records with page citations.

2026-07-13

  • Broader support for other programs' GEDCOM files. Person attributes that used to be invisible — reference numbers, titles, religion, nationality, physical description, generic facts, and funeral/military/medical events — now show in Edit mode and merge like any other event.
  • Matching recognizes record identifiers (_UID/UID) and FamilySearch person ids: two records carrying the same id match with certainty (🔑), even across programs.
  • GEDCOM version migration. An incoming file in a different version (5.5.1 ⇄ 7.0) is migrated to your main file's version on load, so merged records stay valid.
  • Better display of photos from other programs — primary-photo flag, face crops, ordering and keywords are honoured.
  • The Health check now explains the custom tags other programs leave in a file, instead of only listing them.

2026-07-12

  • Tools scans run in the background. Health check, Find duplicates, Normalize and Sources no longer freeze the app on large files, and finished results are kept as you switch tabs.
  • New Age option on charts and reports: each person's age shows next to their lifespan and event dates.
  • Search now ignores accents — typing Ziva finds Živa, Skofja finds Škofja.

2026-07-11

  • Much more compact Edit mode. Each event fits on a single line, with a hover-only + Add menu for extra details, so empty fields no longer clutter the view.
  • Full keyboard editing: Tab through every field and press Enter to open the event-type, Sex and + Add menus.

2026-07-10

  • Tools → Find Duplicates gains a Reject action: rejected pairs are remembered and can be reviewed and un-rejected later.
  • The footer now shows the app version, linking to this changelog.
  • New Verify button (Chrome/Edge): checks whether a loaded file has changed on disk and offers to reload it.

2026-07-06

  • New Settings → Display → Show ages toggle: ages next to lifespans and event dates, plus a full year/month/day breakdown in tooltips.
  • Photos are now called media everywhere, with support for SVG and PDF files, dragging files straight in, and marking a person's region on a group photo to use as their thumbnail.
  • Reports gained an RTF export, an optional table of contents, and living-person redaction.
  • Added support for GEDCOM files exported from MyHeritage.

2026-07-04

  • New Report chart kind: an Ahnentafel ancestor report and an NGSQ-style descendant register, each available as a compact list or as flowing narrative prose — in English and Slovenian.
  • The Charts hub now brings Tree, Grid, Fan, Circle, Timeline, Relationship and Report together under one tab strip, with a shared GEDCOM / SVG / PDF export menu.

2026-07-01

  • GED Merge is now an installable, fully offline-capable app (PWA).
  • Optional local persistence: turn it on and a reload restores your loaded files and progress.
  • Added global search across the whole file.

2026-06-30

  • Set a start person and see everyone ranked by kinship distance, colour-coded by paternal or maternal line.

2026-06-29

  • Health check now flags pedigree loops (a person who is their own ancestor) and sex/role mismatches.

2026-06-28

  • Added Grid, Fan and Circle chart types alongside the family tree.

2026-06-27

  • Added the relationship diagram, and a Privacy tool that redacts living people before you share a file.
  • Any chart can now be exported as SVG or PDF.
